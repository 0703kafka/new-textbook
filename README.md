# 《信息系统分析与设计》数字教材与智能体实验资源

苏州大学《信息系统分析与设计》（ISAD）课程配套资源，面向信息资源管理专业本科生。课程数字教材以信息系统分析与设计方法为主线，并结合智能体与低代码（扣子 Coze）案例和实践。

> 在线站点原发布地址：<https://sghpedc5279.github.io/isad-textbook/>。该地址是否已同步到当前目录结构，请以实际部署版本为准。

## 如何使用

- **浏览数字教材**：从 [`html教材/index.html`](html教材/index.html) 进入并选择章节。
- **体验章节练习**：在 [`games/`](games/) 中打开对应章节的 `game_chNN.html`。
- **运行智能体实验**：先阅读 [`智能体实验复刻/README.md`](智能体实验复刻/README.md)、[`智能体实验复刻/跟练实验说明.md`](智能体实验复刻/跟练实验说明.md) 和各实验目录中的说明。实验依赖、API 密钥及硬件要求因项目而异，不要把整套实验视为一次性安装包。
- **构建实验项目电子书**：参照 [`智能体实验复刻/EPUB.md`](智能体实验复刻/EPUB.md)；PDF、网站及实验环境的构建方式也以该项目文档为准。

## 网页入口与资源路径

GitHub Pages 根目录的 [`index.html`](index.html) 会跳转至 [`html教材/index.html`](html教材/index.html)；根目录 `ch01.html` 至 `ch09.html` 保留旧链接并跳转到对应章节。章节源码继续位于 `html教材/`，通过 `../style.css`、`../app.js`、`../images/`、`../media/` 和 `../games/` 引用根目录资源。附录保留在根目录，章节内链接已对应调整。仓库当前不包含课堂测试 PPTX、教材使用说明 DOCX 或数字教材离线 ZIP，因此网页不再显示这些失效下载入口。
